# FinTrack Pro

FinTrack Pro is a modern personal finance management application built with React and Firebase. It allows users to track their income and expenses, manage transactions, and visualize their financial data through charts and analytics.

## Features

- 🔐 **User Authentication**: Secure sign-up, login and password recovery
- 💰 **Transaction Management**: Add, edit, and delete income and expense transactions
- 📊 **Financial Analytics**: Visualize your spending patterns with interactive charts
- 📱 **Responsive Design**: Works seamlessly across desktop, tablet, and mobile devices
- 📑 **Data Export**: Export your transaction data to PDF and Excel formats
- 🛡️ **Data Security**: All your financial information is securely stored in Firebase

## Technologies Used

- **Frontend**: React, Material UI, Chart.js
- **Backend**: Firebase (Authentication, Realtime Database)
- **Data Visualization**: Chart.js
- **Data Export**: jsPDF, xlsx

## Getting Started

### Prerequisites

- Node.js (v14+)
- npm or yarn

### Installation

1. Clone the repository

   ```
   git clone https://github.com/Abhishek-Pandey786/FinTrack-Pro.git
   cd FinTrack-Pro
   ```

2. Install dependencies

   ```
   npm install
   ```

3. Set up your Firebase project and add your Firebase configuration to the project

4. Start the development server
   ```
   npm start
   ```

## Usage

1. Create an account or log in
2. Add your income and expense transactions
3. View your financial summaries and analytics
4. Export your data as needed
